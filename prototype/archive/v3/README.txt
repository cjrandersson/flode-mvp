flöde~ — Prototype 03

FOCUS OF THIS ITERATION
• Larger, calmer Simplr-like waveform areas
• More exact pod proportions and visual hierarchy
• Drag loop start/end handles directly in each waveform
• Clickable transient markers
• Pod FX redrawn as one continuous hardware-style strip
• Master FX modules can now be dragged to reorder
• Click a master FX module without dragging to bypass/enable it
• Cleaner presentation labels and denser hardware-like spacing
• No reactive/flashing modulation UI
