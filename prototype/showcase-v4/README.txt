flöde~ — Showcase Build 04

This iteration focuses on the six individual samplers and their waveform UX.

VISUAL DIRECTION
- Inspired by Ableton Simpler/Simpler-style sampling workflow: waveform first, controls second.
- Matte charcoal / old workstation grey shell with restrained amber-orange sample graphics.
- Dense, mechanical information hierarchy rather than rounded web-app cards.

NEW IN SHOWCASE 04
- Larger waveform display in every pod.
- Orange sample waveform with a dedicated timing ruler.
- Slice/transient markers extend through the waveform and are numbered.
- Selected transient is highlighted.
- Stronger start/end loop handles and playhead.
- Compact status strip directly under every waveform.
- Each pod reads more clearly as a real sampler rather than a generic control panel.
- Existing drag/drop waveform loading, loop editing, transient selection, random modes, choke groups, per-pod FX, master FX reordering and floating BPM window remain.

This is still a visual/UX prototype. It does not implement the final Max/MSP DSP engine.
