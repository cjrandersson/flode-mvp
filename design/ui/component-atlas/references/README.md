## Per-image analysis template

When a picture is available, record its filename, provenance and review date. Describe observed hierarchy, geometry, typography, colour semantics, interaction clues and motion clues. Then specify transferable principles, elements to omit, proposed flöde~ adaptations and any uncertain interpretation.

For a static image, mark motion as an inference or question; do not present animation behavior as something observed. Record each image separately, rather than treating a collection as one style.

The current atlas proposals use the written/source references listed in the [atlas README](../README.md). They are not a completed extraction from the uninspected pictures.
