# flöde~ build plan

1. **Core engine** — buffer~, waveform~, groove~, loop, speed, volume, pan, stereo out.
2. **Sampler UX** — waveform start/end, scrub/playhead, zoom, fades, Panic.
3. **Transient slicing** — slice markers, density, transient analysis.
4. **Jungulator/random engine** — original Jung controls, RND, RND2, random modes, jitter/pitch.
5. **Clock/sync** — master BPM, MIDI/host clock, Sync/Free, quantization and meters.
6. **Six pods** — duplicate the validated Pod component A–F, routing, mute/solo/record, choke groups.
7. **Pod FX** — LP/HP, tape/saturation, compressor, 3-band EQ.
8. **Master** — reorderable reverb, echo, delay, drive, limiter, master output/record.
9. **UI polish** — Presentation Mode/custom UI, scaling, precision interaction, final visual pass.
