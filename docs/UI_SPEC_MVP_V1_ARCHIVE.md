# UI Spec — Signal POD MVP v1

## Principles
- One strong hierarchy: waveform → mix → generative controls → performance actions.
- Large horizontal sliders instead of small plastic knobs.
- Avoid dashboard density. Advanced functions remain outside the primary surface.
- Dark graphite base, thin borders, restrained typography.
- Pod A accent: blue. Volume/generative depth: teal. Jitter: acid-sage.
- Primary hit areas are intentionally large and horizontally readable.

## Main surface
1. Header: `flöde~ / SIGNAL POD A`
2. Large drag/drop waveform
3. Volume + Pan
4. GEN MODE selector
5. Random/Jung + Jitter
6. GEN RUN, Mute, Solo, Loop

## Fors-inspired refinements
The influence is in restraint and systemization: a compact control vocabulary, visually consistent parameter families, and clear accent logic rather than Max-default UI clutter. We do not copy Fors branding or device layouts.
