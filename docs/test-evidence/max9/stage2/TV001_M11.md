The full-sample playback starts on the explicit control request after its short
safety release. The diagnostic 16n stream continues independently; it does not
retrigger or sequence the sample. Normal rate is 1.0; BPM does not timestretch,
pitch-correct or tempo-fit the file. Stop/retrigger cancel the previous pending
transition. DSP-off stops playback; a play request while DSP is off is rejected.

All contract-shaped events remain unsupported for musical execution, including
`hold`. Validation never authorizes slicing, repeat, reverse, offset, randomness
or patterns. The only executable musical path is explicit full-sample forward
playback. `jung_enabled 1` is rejected.
